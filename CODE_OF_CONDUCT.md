# Code of conduct

This project follows the spirit of the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, criticise ideas rather than people,
and keep discussions focused on the code and its users. Harassment, personal
attacks, and discriminatory language are not welcome.

Maintainers may remove comments, close threads, or block accounts that make the
project unpleasant to work on. To report a concern, contact the maintainers
privately (see `SECURITY.md` for the private channel).
